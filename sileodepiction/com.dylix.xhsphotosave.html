XHS原图保存

com.dylix.xhsphotosave
1.0 iphoneos-arm64e 小红书 9.49.1 RootHide

在小红书笔记页呼出面板，选择要保存的图片、实况照片或视频，一键写入系统相册。

所有资源都解析自笔记接口，直取 CDN 上的原始文件 —— 不是截图，也不是压缩过的缩略图。

功能

  • 原图：解析笔记接口直取 CDN 原图
  • 实况照片：保存为真正的 Live Photo，含 still-image-time 元数据轨与 content identifier 双向绑定，相册里长按会动
  • 视频：优先取最高清流（实测最高 1440P），自动带音轨；遇到分片流自动下载音轨并合轨
  • 视频封面：与视频并列为独立项，可单独保存或一起保存
  • 选择面板：4 列网格、垂直滚动，带实况与视频角标、分辨率与时长标注
  • 主页零采集：仅在笔记页采集，主页信息流不产生任何缓存

使用

  1. 打开小红书任意笔记，悬浮球贴在屏幕边缘
  2. 点击悬浮球呼出选择面板
  3. 勾选要保存的图片 / 视频 / 封面
  4. 点「保存 N 张」写入系统相册
  5. 悬浮球可拖动，松手自动吸附到最近的边缘，3 秒无操作自动缩小

环境

  • 小红书 9.49.1 · RootHide rootless · arm64e
  • 架构为 iphoneos-arm64e，覆盖 A12 及更新设备
  • 其他小红书版本、其他越狱方案未验证

说明

小红书升级后接口字段可能变化，导致解析不到图片。此时面板会提示「没有获取到图片」，日志里能看到原因。
依赖小红书客户端内部接口，仅供自用备份自己有权保存的内容。
